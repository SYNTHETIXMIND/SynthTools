# SynthWorks

**A slim Windows workspace for your project folders.** Keep your Workfolders in a sidebar and open each one in its own tab with PowerShell terminals, Claude Code buttons, a file panel and a basic editor.

More information: [synthetixmind.com](https://synthetixmind.com/pages/tools.php?utm_source=SynthWorks&utm_medium=github&utm_campaign=SynthWorks)

## Features

- Workfolders in a sidebar: add, rename, reorder, color, missing-path check
- One tab per Workfolder with PowerShell 7 terminals (ConPTY), sub-tabs and Claude / Claude (continue) buttons
- File panel: fast tree, live refresh, filter, create, rename, Recycle Bin, copy/cut/paste, drag and drop
- Editor with tabs, conflict-safe saving, encoding and line endings preserved, unsaved backup every 7 s
- Details panel per Workfolder: description, todo, links, exclude list
- No orphaned processes: closing SynthWorks ends every program it started
