# SynthLauncher

**One place for all SYNTHETIXMIND tools on Windows.** SynthLauncher lists every tool with its app icon, installs it, tells you when an update is ready, updates it with one click and starts it. It also keeps itself up to date.

More information: [synthetixmind.com](https://synthetixmind.com/pages/tools.php?utm_source=SynthLauncher&utm_medium=github&utm_campaign=SynthLauncher)

## Features

- Install, update, open and uninstall every SynthTool from one window
- Shows installed and latest version for each tool
- Downloads only from synthetixmind.com; every installer and icon is checked against a signed catalog (Ed25519 + SHA-256) before it is used
- Works offline with the last verified catalog
- Updates itself through the same catalog
