# SynthSize

**See what fills your drives.** SynthSize scans a drive or folder, sorts every subfolder by size and lets you open, copy, cut or delete the space hogs right from the tree.

More information: [synthetixmind.com](https://synthetixmind.com/pages/tools.php?utm_source=SynthSize&utm_medium=github&utm_campaign=SynthSize)

## Features

- Parallel scan of any drive, folder or network path, largest items first
- Size, file and folder count, share of the parent and newest change for every folder
- Item menu: open in Explorer, cut/copy to the clipboard, rename, delete (Recycle Bin or permanent), properties
- Optional Explorer context-menu entry "Analyze with SynthSize"
