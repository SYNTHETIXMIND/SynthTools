# SynthDiff

**Compare two folders on Windows.** SynthDiff lists every file and folder that is new, missing or changed. Copy items to the other side, cut, copy or delete them right from the list, one or many at a time.

More information: [synthetixmind.com](https://synthetixmind.com/pages/tools.php?utm_source=SynthDiff&utm_medium=github&utm_campaign=SynthDiff)

## Features

- Compare by size + date (fast) or byte by byte
- Same / Different / Only left / Only right, with per-folder difference counts and filters
- Multi-select, plus a right-click menu: copy to the other side, cut, copy, delete, open in Explorer, properties
- Ignore list (`.git, node_modules, *.tmp`), drag & drop, swap sides, copy a report for Excel
